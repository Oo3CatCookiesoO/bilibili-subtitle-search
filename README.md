# Bilibili 字幕关键词搜索

一个在本机运行的网页工具：按 UP 主 UID 获取视频字幕，保存到本地，并在已下载的字幕中搜索关键词。它读取视频列表、分 P 信息和字幕文本，不下载视频或音频。

## 运行

需要 Python 3.10 或更新版本。在 Windows 上，下载项目文件后双击 `start_web_ui.bat`；也可以在项目目录运行：

```powershell
python .\web_app.py
```

用浏览器打开 `http://127.0.0.1:8765`。网页只在本机提供服务，关闭启动程序的命令窗口后服务会停止。

程序主体使用 Python 标准库。如果希望网页扫码登录时生成二维码图片，可额外安装：

```powershell
python -m pip install "qrcode[pil]"
```

## 网页使用方法

1. **先登录**：使用在线扫描和下载前，必须先登录 Bilibili 账号。点击右上角的“扫码登录”；如果无法扫码，也可选择“Cookie 登录”。登录信息保存在本机的 `bili_cookies.txt`，不要分享这个文件。
2. **下载字幕**：在左侧填写 UP 主 UID，按需设置扫描来源、投稿筛选、标题关键词、页码、BV 范围和速度，点击“在线补扫/下载字幕”。不勾选“扫描全部视频”时，会依据本地历史跳过已扫描的内容。
3. **查询字幕**：下载完成后，在右侧“本地字幕搜索结果”填写字幕关键词，点击“本地查询字幕”。可选择已下载的 UP，也可按视频标题筛选。结果显示视频标题、BV 号、分 P、命中的字幕和时间戳；点击时间戳可打开相应的视频位置。
4. **查看进度**：运行日志可翻页。扫描中如需暂停或停止，使用页面上的相应按钮；再次补扫时可继续利用已有缓存和扫描历史。

网页还提供检测 BV、清理 0KB 空字幕及对应历史的操作。清理前会弹出确认提示。

## 本地文件

运行后，程序可能在项目目录生成以下文件或文件夹：

| 路径 | 内容 |
| --- | --- |
| `bili_cookies.txt` | 登录 Cookie，属于敏感信息 |
| `bili_login_qr.png` | 临时登录二维码 |
| `subtitle_cache/` | 已下载的字幕和视频信息 |
| `history/` | 扫描进度与失败记录 |

这些都是本地运行数据，**不要上传到公开仓库**。上传源码时只需选择程序、启动脚本、测试和本 README。

## 注意

- 本工具只能下载视频已有且当前账号可访问的字幕。没有字幕的视频可能留下 0KB 的字幕文件。
- 如果大量原本有字幕的视频也产生 0KB 文件，可能遇到了 Bilibili 的访问限制。可以点击“清理本次空字幕历史”，删除本次扫描产生的 0KB 字幕文件及对应历史记录；等待一段时间后，再以“不扫描全部视频”模式补扫。也可以在符合平台规则的前提下，使用另一个当前可正常访问的账号。
- 请定期清理不再需要的下载字幕。手动删除 `subtitle_cache/` 中的字幕文件**不会**同步删除 `history/` 中的扫描记录；之后选择“不扫描全部视频”时，这些视频仍可能被视为已扫描。需要重新扫描时，请使用网页提供的清理功能处理对应的空字幕历史，或选择“扫描全部视频”。
- Bilibili 接口、访问限制和字幕权限可能变化；遇到请求失败时可稍后重试，并适当降低扫描速度。
- 请遵守 Bilibili 的相关规则，控制请求频率，并尊重字幕与视频内容的权利。
- 宣传与推广：在对外宣传本工具前，请先通过本仓库的 GitHub Issues 联系作者并征得同意；未经许可，请勿以作者或项目官方名义推广本工具。
